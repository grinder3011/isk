💡 How to use the Image Cropper:

  • Upload an image using the button above.
  • Click 'Draw New Crop Area' to select the area you want to crop.
  • Use 'Clear Crop Area' to start over.
  • Use Zoom In and Zoom Out to adjust the view.
  • Once satisfied, click 'Crop' and then 'Download'.
