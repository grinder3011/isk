💡 How to use MultiZip:

  • Use the file picker to select one or more files.
  • Remove individual files by clicking the ❌ button next to each file.
  • Click 'Create Archive' once you’re happy with your selection.
  • Click 'Download Archive' to save the ZIP file.
  • Click 'Remove All Files' to start fresh.
