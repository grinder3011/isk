Filename Rules

💡 How to use File Renamer:

  • Select one or more files to rename.
  • Add a prefix or suffix to customize names.
  • Use the Replace fields to find and replace text in filenames.
  • Preview the new filenames in the preview area.
  • Click “Rename” to apply the changes.
  • Click “Reset” to clear and start again.
